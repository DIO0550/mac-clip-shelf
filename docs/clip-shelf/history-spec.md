# clip-shelf - 履歴ブラウザ仕様（フロントエンド）

> **機能**: [clip-shelf](./index.md)
> **ステータス**: 下書き
> **対応モック**: `design/03-history.html`

## 概要

過去全件のクリップボード履歴を一覧・検索・プレビュー・整理するためのフル機能ウィンドウ。`PastePicker` が「素早く貼る」用途であるのに対し、本ウィンドウは「過去を漁る・整理する」用途を担う。

## サーフェス

| 項目 | 仕様 |
|:-----|:-----|
| 種別 | `NSWindow`（標準ウィンドウ、トラフィックライト3つ表示） |
| サイズ | 初期 840×540、最小 720×440、リサイズ可能 |
| 個数 | シングルウィンドウ。再オープン時は前回サイズ・位置を復元 |
| 位置 | 初回はスクリーン中央、それ以降は `NSWindow` のフレーム保存機能で記憶 |

## レイアウト

3カラム構成。`NavigationSplitView` を使用する。

```
┌──────────────────────────────────────────────────────────────────────┐
│ ● ● ●                          履歴ブラウザ                          │ ← タイトルバー
├──────────────────┬─────────────────────────┬───────────────────────┤
│ サイドバー        │ リスト                  │ プレビュー            │
│ 200px            │ 380px〜可変             │ 200px〜可変           │
│                  │ ┌─────────────────────┐ │  ┌─────────────────┐  │
│ ▸ すべて (524)   │ │🔍 検索...           │ │  │                 │  │
│   📌 ピン留め(8)│ ├─────────────────────┤ │  │ サムネイル/      │  │
│   🅣 テキスト    │ │ ▸ https://...       │ │  │ プレビュー       │  │
│   🅘 画像        │ │   30秒前 ・ 142B    │ │  │                 │  │
│   🅕 ファイル    │ ├─────────────────────┤ │  └─────────────────┘  │
│                  │ │   git rebase -i...  │ │  種別: テキスト       │
│ ─────────────── │ │   2分前 ・ 22B      │ │  サイズ: 142 B        │
│ ▸ 今日 (24)      │ ├─────────────────────┤ │  作成: 2026-05-12     │
│   昨日 (51)      │ │   IMG_2026....png   │ │       12:43:18        │
│   今週 (132)     │ │   5分前 ・ 1.2MB    │ │  ピン留め: なし        │
│   今月 (430)     │ ├─────────────────────┤ │                       │
│                  │ │   diot12345@yahoo..│ │  [📌 ピン留め]        │
│                  │ │   12分前 ・ 18B     │ │  [📋 コピー]          │
│                  │ └─────────────────────┘ │  [🗑️  削除]            │
└──────────────────┴─────────────────────────┴───────────────────────┘
```

## コンポーネント

| コンポーネント | 種別 | 説明 |
|:-------------|:-----|:-----|
| `HistoryWindow` | `Scene` | ウィンドウ本体。`NavigationSplitView` を保持 |
| `Sidebar` | SwiftUI `List` | 種別・期間ファセット |
| `ListPane` | SwiftUI `VStack`（検索バー + 仮想化リスト） | リスト中央カラム |
| `HistoryRow` | カスタム `View` | 1件分の行。`menubar` の行より詳細（メタ・サイズ） |
| `PreviewPane` | SwiftUI `VStack` | 詳細プレビュー + アクションボタン |
| `Toolbar` | `Toolbar`（macOS） | 検索 / 全削除 / ウィンドウメニュー |

## ユーザー操作

| 操作 | トリガー | 振る舞い |
|:-----|:--------|:---------|
| ウィンドウを開く | メニューバー → 「履歴ブラウザを開く」 / `Cmd + Shift + H` | ウィンドウを前面表示 |
| ファセット選択 | サイドバー行クリック | リストを当該条件で絞り込み |
| 検索 | 中央上部の検索フィールド | インクリメンタルにリスト更新 |
| 行選択 | クリック / 矢印キー | プレビューに反映 |
| 複数選択 | `Shift + クリック` / `Cmd + クリック` | 範囲選択 / トグル選択 |
| ピン留め | `Cmd + P` / プレビュー「ピン留め」ボタン / 右クリック | 当該行のピン状態切替 |
| 削除 | `Backspace` / プレビュー「削除」 / 右クリック | 確認ダイアログ後に削除 |
| コピー（書き戻し） | `Cmd + C` / プレビュー「コピー」 | クリップボードに書き戻すのみ |
| ペースト（自動貼付） | `Enter` | クリップボード書き戻し + ウィンドウは閉じない + `Cmd+V` 送信 |
| 全削除 | ツールバー「全削除」 → 確認 | 履歴をすべて削除（ピン留めは除外オプションあり） |

## キーボードショートカット

| キー | 動作 |
|:-----|:-----|
| `Cmd + F` | 検索フィールドにフォーカス |
| `Cmd + 1〜4` | サイドバーのファセット切替 |
| `Cmd + P` | 選択行のピン留め切替 |
| `Cmd + C` | クリップボードに書き戻し |
| `Cmd + Backspace` | 削除（確認ダイアログ） |
| `Enter` | ペースト（フロントアプリへ） |
| `Esc` | 検索クリア → ウィンドウは閉じない（明示的に `Cmd + W` で閉じる） |

## 表示データ

### サイドバー

| ファセット | カウント | 説明 |
|:----------|:--------|:-----|
| すべて | 全件数 | デフォルト選択 |
| 📌 ピン留め | ピン留め項目数 | `pinned_items` に紐づく履歴 |
| 🅣 テキスト | テキスト型件数 | `HistoryItem.kind == .text` |
| 🅘 画像 | 画像型件数 | `HistoryItem.kind == .image` |
| 🅕 ファイル | ファイル型件数 | `HistoryItem.kind == .file` |
| 期間: 今日 / 昨日 / 今週 / 今月 | 各期間件数 | `createdAt` でフィルタ |

### リスト行

| フィールド | フォーマット |
|:----------|:------------|
| プレビュー | 最大2行、テキストは省略表示 |
| メタ行 | 相対時刻 ・ サイズ（バイト / KB / MB） |
| 型アイコン | 左端に SF Symbol |
| ピンバッジ | ピン留め時に行右上に小アイコン |

### プレビューペイン

| フィールド | 表示 |
|:----------|:-----|
| 画像 | 原寸表示（ペインに収まらなければスクロール可能） |
| テキスト | 折返し表示、行数制限なし、コードと思しき内容は等幅フォント |
| RTF | 装飾付きで表示 |
| ファイル | アイコン + フルパス + Finder で表示ボタン |
| メタ | 種別 / サイズ / 作成日時 / ピン留め有無 / ソースアプリ（取得できれば） |

## 状態管理

| 状態名 | 型 | 初期値 | 更新トリガー |
|:-------|:---|:-------|:-----------|
| `selectedFacet` | `Facet` | `.all` | サイドバー操作 |
| `query` | `String` | `""` | 検索 |
| `selectedIDs` | `Set<HistoryItem.ID>` | `[]` | リストでの選択 |
| `sortOrder` | `SortOrder` | `.createdAtDesc` | ツールバーから変更 |
| `items` | `[HistoryItem]` | 起動時に取得 | `HistoryService` 購読 + `query` / `facet` / `sortOrder` |

## アクセシビリティ

| 観点 | 対応方針 |
|:-----|:---------|
| キーボード | `Tab` で 3 ペインを循環、`Cmd+F` で検索 |
| VoiceOver | 各行に種別 + プレビュー + 時刻を読み上げ |
| 文字サイズ | システム設定の `dynamicTypeSize` に追従 |

## エラー表示

| エラーケース | 発生条件 | 表示方法 |
|:------------|:---------|:---------|
| データベース読み込み失敗 | SQLite 破損 | ウィンドウ中央にエラー画面 + 「履歴をリセット」アクション |
| プレビュー画像のデコード失敗 | 履歴データの破損 | プレースホルダ画像 + 「破損データ」ラベル |
| 削除確定中の競合 | 別箇所で同じ項目が削除済 | 何もせず警告ログのみ |

## パフォーマンス

| 指標 | 目標値 | 対策 |
|:-----|:-------|:-----|
| 起動時の初回表示 | 200ms 以下 | リストは仮想化（`LazyVStack`）、初回ロードは最新200件のみで開始 |
| スクロール | 60fps 維持 | サムネイルは行表示時にレイジー生成 |
| 検索フィルタ | 100ms 以下（10,000件時） | SQLite の `FTS5` 仮想テーブルで検索 |

## 制限事項

- 検索は本文先頭1MB のみインデックス対象（巨大な貼り付け本文の全文検索は対象外）
- 期間ファセットの「今月」は単純な月初〜月末で、ローカルタイムゾーン依存
- 複数選択でのバッチ操作は MVP では「削除」「ピン留めON/OFF」のみ
